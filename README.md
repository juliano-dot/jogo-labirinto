# jogo-labirinto

Este projeto é um jogo de labirinto simples, criado em HTML, CSS e JavaScript para ser executado no navegador.

## Como jogar

- Use as setas do teclado ou os botões de direção na tela.
- Vá coletando as moedas espalhadas pelo labirinto.
- Quando todas as moedas forem coletadas, a saída fica liberada.
- Chegue até a saída para vencer.

## Como executar

No terminal, dentro da pasta do projeto, execute:

```bash
python3 -m http.server 8000
```

Depois abra no navegador em:

```text
http://localhost:8000
```

## Estrutura dos arquivos

- `index.html` — estrutura do jogo
- `style.css` — estilos do tabuleiro e elementos visuais
- `script.js` — lógica do labirinto, movimentação, moedas e vitória
